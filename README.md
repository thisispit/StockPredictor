# python-test

Repository generated by ChatGPT — contains code to fetch NSE OCLHV data (INFY, TCS, NIFTY IT), compute features, visualize with Bokeh, and run quick sklearn models with pytest tests.

**How to use (summary)**
1. Install dependencies: `pip install -r requirements.txt yfinance`
2. Fetch data: `python data_fetch.py --tickers INFY.NS TCS.NS --index ^NSEI --start 2000-01-01 --end 2023-12-31`
3. Create features: `python features.py --input-dir data --output-dir processed`
4. Visualize: `python visualize_bokeh.py --input processed --out plots`
5. Run models: `python models.py`
6. Run tests: `python -m pytest -q`
7. Quick prediction CLI: `python stockpredictor.py INFY`
8. Run Dashboard: `python dashboard.py INFY` (replace INFY with desired stock symbol, defaults to INFY)

**Project Directories:**
*   `data`: Stores raw stock data.
*   `processed`: Stores cleaned and feature-engineered data.
*   `models`: Stores trained machine learning model files.
*   `plots`: Stores Bokeh visual charts (HTML).
*   `tests`: Contains automated pytest scripts.

See individual files for more details.
